# yt-draft — 대본 골격 + 샷 리스트 규칙

입력은 `ytc draft context <category> <motif-id|archetype-id> [--topic 주제]`의 JSON이다. 출력은 draft JSON 하나다.
목표: **오늘 바로 찍을 수 있는** 기획안. 무엇을 말하고(대사·자막), 무엇을 어떻게 찍을지(샷)가 섹션마다 정해져 있어야 한다.

## 1. 뼈대 정하기

- 출처가 모티브 카드면 카드의 `이렇게`·`바탕`을 뼈대로 쓴다. 카드에 아키타입(바탕: A1 …)이 있으면 `archetype`에 그 id를 넣는다.
- 출처가 아키타입이면 그 골격(skeleton)과 평균 비율(mean_ratio)·평균 길이를 따른다.
- **섹션 비율은 아키타입 평균에서 ±10%p 안**으로 맞춘다. 일부러 벗어나려면 이유를 `script`나 `prep`이 아니라 사용자에게 말로 설명한다.
- 길이: 쇼츠면 아키타입 평균 길이(없으면 45~60초), 롱폼이면 사용자에게 묻는다.

## 2. 섹션별 대본 (`script`)

- 말로 할 대사와 화면 자막을 구분해 쓴다: `말: …` / `자막: …`. 말 없는 영상이면 자막만.
- 훅은 hook_type 정의대로 첫 문장·첫 화면을 구체적으로 쓴다(설계서 5.1, yt-analyze 2절).
- 문장은 짧게. 쇼츠는 한 섹션에 2~4줄.

## 3. 샷 리스트 (`shots`)

- 샷 하나 = 컷 하나. **샷 수 = 그 섹션의 컷 수**다.
- 샷 길이 합이 섹션 길이와 같게 한다.
- 컷 길이는 아키타입의 pacing을 따른다(예: 평균 컷 1.3초 → 본론 샷은 1~2초, 훅은 더 짧게).
- size는 반드시 다음 중 하나: `익스트림 클로즈업` `클로즈업` `바스트` `미디엄` `와이드` `탑뷰` `POV` `인서트`
- angle은 자유(정면, 45도, 탑뷰, 로우앵글 …), action은 "무엇이 화면에 보이고 무엇을 하는지" 한 줄.
- 같은 샷이 연속 반복되면(점프컷 연속) 하나씩 다 적는다. 편집 리듬이 그대로 보이게.
- `profile`의 피하고 싶은 스타일을 지킨다(예: 얼굴 출연 회피 → 바스트·정면 대신 탑뷰·손 클로즈업·인서트).

## 4. 출력 (draft JSON)

```json
{
  "title": "편의점 컵라면 맵기 4단계 도전!",
  "topic": "편의점 라면",
  "source": "M-mukbang-001",
  "archetype": "A2",
  "hook_type": "question",
  "narrative_type": "list",
  "sections": [
    {"label": "hook", "start": 0, "end": 2, "script": "자막: 4단계 다 먹을 수 있을까?",
     "shots": [{"size": "탑뷰", "angle": "탑뷰", "sec": 2, "action": "컵라면 4개 나란히, 상단 단계 아이콘"}]},
    {"label": "body", "sub": "list_item", "start": 2, "end": 40, "script": "자막: 1단계 순한맛 → … (단계마다 한 줄 감상)",
     "shots": [{"size": "클로즈업", "angle": "45도", "sec": 1.5, "action": "1단계 뚜껑 열기"},
               {"size": "클로즈업", "angle": "탑뷰", "sec": 1.5, "action": "면 들어 올리기"}]},
    {"label": "outro", "start": 40, "end": 45, "script": "자막: 4단계는… 다음엔 불닭 5종?",
     "shots": [{"size": "탑뷰", "angle": "탑뷰", "sec": 5, "action": "빈 컵 4개"}]}
  ],
  "prep": ["컵라면 4종(순한맛→불닭)", "폰 탑뷰 거치대", "물컵"]
}
```
(예시는 짧게 줄였다. 실제로는 본론 샷을 모두 적는다.)

## 5. 사용자에게 보여 줄 형식

```
📝 편의점 컵라면 맵기 4단계 도전! (45초 · 컷 28개 · 평균 1.6초)
출처: M-mukbang-001 · 아키타입 A2 단계별 도전 리스트형

0:00–0:02 hook   자막: 4단계 다 먹을 수 있을까?      [탑뷰 2초]
0:02–0:40 body   단계마다 뚜껑→면→한 입→반응 자막   [클로즈업 1.5초 × 24]
0:40–0:45 outro  빈 컵 4개 + 다음 편 예고            [탑뷰 5초]

준비물: 컵라면 4종, 탑뷰 거치대, 물컵
```
묻는다: "이대로 저장할까요? 고칠 곳이 있으면 말해 주세요."
