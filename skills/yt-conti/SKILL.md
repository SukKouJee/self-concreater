# yt-conti — 전체 대사 + 컷별 가이드 규칙

입력은 `ytc conti context <draft.md>`의 JSON이다. 출력은 conti JSON 하나다.
목표: **촬영 현장에서 이 한 장만 보고 찍을 수 있는** 콘티. 컷마다 무엇이 보이고, 무엇을 말하고, 어떻게 움직이는지가 정해져 있어야 한다.

## 1. 전체 대사 먼저 (`script`)

- draft 섹션마다 하나씩, **같은 순서로** 쓴다(`sections`의 개수와 같아야 한다).
- draft 섹션의 `script`(`말:` / `자막:`)를 바탕으로, 영상 전체가 한 사람의 말처럼 이어지게 다듬는다. 섹션 사이 연결 말(“자, 다음은…”)을 챙긴다.
- `text`에는 **입으로 하는 말만** 쓴다. 화면 자막은 컷의 `caption`으로 보낸다.
- 길이 예산: 섹션의 `max_chars`(= 말 속도 × 섹션 길이)의 **70% 안**. 먹방·요리처럼 먹고 만드는 시간이 필요한 영상은 50% 안. 말 속도는 `speech_cps`(레퍼런스 실측)다.
- 말 없는 영상이면(draft에 `말:`이 없고 profile이 말 없는 스타일) `text`는 빈 문자열로 두고 자막·효과음으로 끌고 간다.
- 훅 섹션의 첫 문장은 draft의 hook_type을 지킨다(question이면 질문으로, result_first면 결과부터).

## 2. 컷 뼈대 (`cuts`)

- draft의 샷 표가 컷 뼈대다. **샷 하나 = 컷 하나**, 순서·크기·앵글·행동을 그대로 가져온다.
- 섹션별 컷 길이 합은 섹션 길이와 같아야 한다(±0.3초). draft 표의 길이 합이 다르면 컷 길이를 고르게 조정한다.
- 컷을 쪼개거나 합치는 것은 대사가 도저히 안 들어갈 때만. 그때는 사용자에게 이유를 말한다.
- draft가 대본만 있는 경우(`script_only`, 샷 표 없음): 섹션 길이를 아키타입 평균 컷(없으면 쇼츠 1.5초·롱폼 4초)으로 나눠 컷을 만들고, `shot_sizes` 중에서 고른다.
- `section`은 컷이 속한 섹션 번호(context `sections[].idx`, 0부터).

## 3. 컷마다 넣을 것

| 필드 | 내용 |
|---|---|
| `line` | 전체 대사 중 **이 컷에서 하는 부분**. 섹션의 컷 `line`을 순서대로 이으면 그 섹션 `text`와 같아야 한다(띄어쓰기·문장부호 무시). 말 없는 컷은 `""` |
| `caption` | 화면 자막. draft의 `자막:`을 해당 컷에 배치. 없으면 `""` |
| `sfx` | 효과음·BGM 큐(후루룩, 띵, BGM 전환 등). 없으면 `""` |
| `guide` | **이 컷을 찍는 사람에게 주는 한 줄 지시**. 필수 |

`guide` 쓰는 법 — 동사로, 구체적으로, 한 컷에 하나의 핵심:
- 몸·손: “젓가락으로 면을 높이 들고 1초 멈춘다”, “엄지척은 프레임 오른쪽 아래에서”
- 표정·톤: “놀란 톤으로 짧게”, “속삭이듯”
- 카메라: “폰 고정(탑뷰 거치대)”, “살짝 밀어 들어가기”, “초점은 면발”
- 편집: “다음 컷과 점프컷”, “자막은 소리와 동시에”
- profile의 피하고 싶은 스타일을 지킨다(얼굴 출연 회피 → 얼굴이 보이는 지시 금지).

## 4. 대사 길이 확인

- 컷 `line`의 글자 수(공백·문장부호 제외)가 `speech_cps × sec`를 넘으면 저장 후 `line_too_long` 경고가 나온다.
- 미리 피한다: 1초 컷에는 4자 안팎, 2초 컷에는 8자 안팎. 넘치면 다음 컷으로 넘기거나 문장을 줄인다.

## 5. 출력 (conti JSON)

```json
{
  "script": [
    {"text": "편의점 컵라면 맵기 4단계, 끝까지 갈 수 있을까?"},
    {"text": "1단계 순한맛부터. 음, 이건 물 필요 없겠다. 2단계… 슬슬 칼칼한데?"},
    {"text": "4단계는… 이건 아니다. 다음 단계 추천은 댓글로!"}
  ],
  "cuts": [
    {"section": 0, "size": "탑뷰", "angle": "탑뷰", "sec": 1.0, "action": "컵라면 4개 나란히, 상단에 단계 아이콘",
     "line": "편의점 컵라면 맵기 4단계,", "caption": "맵기 4단계 도전", "sfx": "띵",
     "guide": "폰 탑뷰 거치대 고정, 컵은 순한맛→불닭 순서로 왼쪽부터"},
    {"section": 0, "size": "인서트", "angle": "탑뷰", "sec": 1.0, "action": "화살표가 1단계 아이콘 위로",
     "line": "끝까지 갈 수 있을까?", "caption": "", "sfx": "",
     "guide": "질문 끝을 올려서, 젓가락 든 손이 오른쪽에서 들어온다"}
  ]
}
```
(예시는 줄였다. 실제로는 draft의 모든 컷을 적는다.)

## 6. 사용자에게 보여 줄 형식

```
🎬 편의점 컵라면 맵기 4단계 도전! — 콘티 (45초 · 컷 36개 · 말 속도 초당 4.4자 기준)

[전체 대사]
0:00 hook   편의점 컵라면 맵기 4단계, 끝까지 갈 수 있을까?
0:02 body   1단계 순한맛부터. 음, 이건 물 필요 없겠다. …
0:40 outro  4단계는… 이건 아니다. 다음 단계 추천은 댓글로!

[컷] (처음 6컷 + 섹션이 바뀌는 컷)
#1 0:00 탑뷰 1초   "편의점 컵라면 맵기 4단계,"   자막: 맵기 4단계 도전   🔊 띵
   → 폰 탑뷰 거치대 고정, 컵은 순한맛→불닭 순서로 왼쪽부터
#2 0:01 인서트 1초 "끝까지 갈 수 있을까?"
   → 질문 끝을 올려서, 젓가락 든 손이 오른쪽에서 들어온다
…
```
묻는다: "이대로 저장하고 스토리보드(HTML)를 만들까요? 대사나 가이드를 고칠 곳이 있으면 말해 주세요."
