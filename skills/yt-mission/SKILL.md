# yt-mission — 미션·피드백·회고 규칙

입력은 `ytc mission context`(미션) 또는 `ytc mission week`(회고)의 JSON이다.

## 1. 성장 단계 (profile `## 성장 단계`)

| 단계 | 뜻 | 미션 성격 | 예 |
|---|---|---|---|
| 관찰 | 보는 눈을 기르는 중 | 레퍼런스를 정해진 관점으로 뜯어보기 | "A1 영상 하나에서 컷 바뀌는 순간 10개 받아 적기" |
| 모방 | 그대로 따라 해 보기 | 기법·샷 하나를 똑같이 재현 | "탑뷰 손 클로즈업 15초 찍기" |
| 제작 | 내 것으로 한 편 | ★카드·기획안의 한 섹션씩 실제 제작 | "기획안의 훅 3초를 찍고 컷 편집" |
| 변형 | 비틀기 | 아키타입에서 한 가지를 일부러 바꿔 보기 | "A1 구조에 각도 카드의 소재를 넣어 찍기" |

단계는 미션이 바꾸지 않는다. 회고에서 근거가 쌓이면 다음 단계를 **제안**한다.

## 2. 재료 우선순위

1. `starred`(★ 모티브 카드) — 사용자가 고른 발상. 가장 먼저 쓴다.
2. `drafts`(최근 기획안) — 기획안이 있으면 그 섹션 하나를 찍거나 다듬는다.
3. `gaps`(진단 갭, intentional 제외) — 갭 하나를 연습 과제로 바꾼다(예: structure:intro → "인트로 5초 안에 끝내기 연습").
4. 아무것도 없으면 관찰 미션(레퍼런스 뜯어보기).
- `history`에서 최근 이틀과 같은 kind·같은 재료는 피한다. 건너뛴 미션의 `skip_reason`이 '시간'이면 더 작게, '재료 없음'이면 준비물 없는 미션으로.

## 3. 크기

- `recommended.minutes`를 그대로 쓴다(스크립트가 난이도 평가로 조정했다). `adjust`가 easier면 단계 수를 줄이고, harder면 결과물 기준을 한 단계 올린다.
- 하루 1개(사용자가 원하면 2개, 합계가 minutes 안).
- **촬영 미션을 자주 넣는다**(모방 이상 단계에선 주 3회 이상). 촬영 미션은 샷 크기·앵글·길이를 숫자로: "탑뷰, 손만, 15초 원컷".
- profile `피하고 싶은 스타일`을 지킨다.

## 4. 미션 JSON

```json
{
  "title": "탑뷰 손 클로즈업 15초 찍기",
  "kind": "촬영",
  "minutes": 20,
  "source": "M-mukbang-001",
  "why": "★카드 '편의점 컵라면 맵기 4단계'의 핵심 샷을 먼저 연습한다",
  "steps": ["폰을 그릇 위 탑뷰로 고정(거치대 없으면 책 두 권)", "면을 들어 올리는 손만 15초 원컷", "같은 샷을 손 위치 바꿔 2번 더"],
  "deliverable": "15초 클립 3개 중 가장 나은 1개"
}
```
kind: 관찰 · 분석 · 기획 · 촬영 · 편집 · 업로드

## 5. 제출 피드백

- 2~4문장. **잘된 점 1개 → 다음에 바꿀 점 1개(구체적 행동)**. 점수 매기지 않는다.
- 제출물이 파일이면 가능한 범위에서 본다(이미지·텍스트는 Read). 영상은 사용자가 말해 준 내용으로 판단한다.
- 마지막에 난이도를 묻는다: "오늘 미션 난이도는 어땠나요? 쉬움 / 적당 / 어려움" → easy / right / hard.

## 6. 주간 회고 (`/yt-review`)

`week` JSON으로:
- `summary`: 미션 완료율, 많이 한 종류, 레퍼런스·모티브가 얼마나 쌓였는지 2~3문장.
- `repeated_weakness`: 피드백·skip 사유·진단 갭에서 **두 번 이상** 나온 것만.
- `next_week`: 다음 주 미션 방향 2~3개(종류·재료).
- `profile_proposal`: 바꿀 프로필 섹션만. `강점`·`약점`은 bullet 문자열, `성장 단계`는 관찰·모방·제작·변형 중 하나.
  - 단계 올림 기준: 지난주 완료율 70% 이상 + 그 단계 미션 대부분 easy/right + 다음 단계 재료(예: 제작이면 ★카드나 기획안)가 있다.
  - 근거가 약하면 제안하지 않는다.

```json
{"summary": "…", "repeated_weakness": ["손이 화면 밖으로 나감"], "next_week": ["탑뷰 고정 촬영 3번", "컷 편집 1번"],
 "profile_proposal": {"약점": "- 프레이밍(손 위치)", "성장 단계": "모방"}}
```
