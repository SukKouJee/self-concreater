## 무엇을 하나요
기획안 하나가 영상 한 편입니다. 메뉴의 **내 영상**(폰은 아래 "내 영상" 탭)에 만들고 있는 영상이 진행 막대와 지금 단계로 나오고, 영상을 누르면 그 영상의 작업 공간이 열립니다.
작업 공간은 위에서부터 제목과 메타 줄(시작일 · 목표 길이 · 출처 모티브 · 유형), 여섯 단계 진행 카드(기획안 / 다듬기 / 콘티 / 촬영 / 편집 / 진단), 그리고 탭 네 개(**기획안 / 콘티 / 촬영 체크 / 진단**)입니다. 진행 카드 오른쪽에는 지금 단계에 맞는 행동(예: 촬영 차례면 "폰 촬영 모드"와 "다 찍음")이 나옵니다.
이 도움말은 **기획안 탭**과 새 기획안 만들기를 설명합니다. 기획안은 모티브 카드나 아키타입(또는 지인의 기획안 틀)을 출처로 섹션별 대본과 샷 리스트를 만든 것이고, 샷은 크기·앵글·길이·내용으로 적힙니다.

## 사용 예
1. 새 영상은 [모티브](#/motif)에서 카드를 골라 "이 카드로 새 영상 시작"을 누르면 시작됩니다(사이드바와 내 영상의 "+ 새 영상 시작"도 모티브로 갑니다). 아키타입이나 지인 틀로 시작하려면 [새 기획안](#/draft/new) 화면에서 출처를 고릅니다. 주제와 목표 길이(5~1800초)는 선택입니다.
2. "기획안 만들기"를 누르고 기다립니다. 기다리는 동안 다른 화면으로 가도 머리말의 작업 상태 칩이 진행을 보여 줍니다.
3. 미리보기에서 제목·섹션별 대본·샷 표·준비물을 고치고 "저장"합니다. 샷은 추가·삭제할 수 있습니다. 저장하면 그 영상의 작업 공간(기획안 탭)이 열립니다.
4. 기획안 탭에서 "훅·제목·썸네일 다듬기"를 누르면 훅 5개, 제목 10개, 썸네일 지시서 후보가 점수·지적과 함께 나옵니다. 마음에 드는 것을 골라 고친 뒤 "저장(기획안에 반영)"합니다.
5. 다음은 콘티 탭에서 콘티를 만듭니다.

## 이렇게 나와요
```
내 영상 › 편의점 컵라면 맵기 4단계 도전!
| 편의점 컵라면 맵기 4단계 도전!
  10월 25일 시작 · 목표 0:45 · [모티브 결과 선공개] [A2]
  ✓기획안 – 다듬기 ●콘티 ○촬영 ○편집 ○진단                 [콘티 만들기]
  [기획안] 콘티  촬영 체크  진단

0:00–0:02 훅    자막: 4단계 다 먹을 수 있을까?      [탑뷰 2초]
0:02–0:40 본문  단계마다 뚜껑→면→한 입→반응 자막   [클로즈업 1.5초 × 24]
0:40–0:45 아웃트로  빈 컵 4개 + 다음 편 예고          [탑뷰 5초]
준비물: 컵라면 4종, 탑뷰 거치대, 물컵
```

## 알아 둘 것
- 출처가 하나도 없으면 고를 수 없습니다. 먼저 모티브 카드나 아키타입을 만드세요.
- 만들기와 다듬기는 각각 Claude를 한 번 부르고 수십 초가 걸립니다. 미리보기와 후보 단계에서는 아무것도 바뀌지 않고, 저장해야 기록됩니다.
- 미리보기에서는 섹션 구간과 라벨은 고칠 수 없습니다. 섹션마다 샷이 하나 이상 있어야 저장할 수 있고, 샷 길이의 합이 섹션 길이와 다르면 경고만 나옵니다. 샷 크기는 정해진 목록(익스트림 클로즈업, 클로즈업, 바스트, 미디엄, 와이드, 탑뷰, POV, 인서트)에서 고릅니다.
- 아키타입 출처이면 섹션 비율 차이가 10%p를 넘는 곳에 "차이 큼" 표시가 붙습니다.
- 다듬기에서 반영하는 것은 제목, 훅 대본(필요하면 훅 유형), 기획안 패키징 칸의 썸네일 지시서입니다. 샷 표와 내 메모 칸은 건드리지 않습니다. 그 사이 기획안이 바뀌었으면 저장하지 않고, 이미 콘티가 있으면 콘티를 다시 만들어야 훅이 반영됩니다.
- 진행 카드의 단계는 기존 기록으로 계산합니다. 다듬기와 편집은 건너뛰어도 되는 단계이고(편집은 자막 영상이 있으면 끝난 것으로 봅니다), 알 수 없는 단계는 "–"로 둡니다. 촬영 수(촬영 N / M장면)는 이 브라우저에서 체크한 장면이라 다른 기기와 나누지 않습니다.
- 콘티 편집처럼 저장하지 않은 입력이 있으면 탭이나 화면을 옮기기 전에 화면 안에서 "버리고 이동 / 계속 편집"을 묻습니다.
- 기획안 탭의 "기획안 삭제"는 기획안과 그 기획안의 콘티(스토리보드, SRT·자막 영상 포함)를 휴지통으로 옮깁니다. 잘못 지웠으면 관리자에게 문의하세요(지운 것은 휴지통에 보관됩니다). 다듬기·콘티 만들기·자막 작업이 도는 중에는 삭제할 수 없습니다.
- 목표 길이를 비워 두면 Claude가 정합니다. 쇼츠는 아키타입 평균 길이(없으면 45~60초)를 기준으로 하도록 되어 있고, 롱폼은 길이를 직접 적는 편이 안전합니다.
