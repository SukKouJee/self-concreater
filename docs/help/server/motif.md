## 무엇을 하나요
메뉴 영감 › **모티브**입니다. 내 레퍼런스를 바탕으로 "무엇을 어떤 흐름으로 찍을지" 아이디어 카드를 뽑아 주고, 고른 카드로 새 영상을 시작합니다. 카드는 네 종류입니다. 기법(떼어 쓸 수 있는 훅·전환·엔딩·촬영 한 가지), 각도(레퍼런스가 덜 다룬 주제나 관점), 흐름(아키타입 골격을 내 주제에 적용), 조합(구조와 서로 다른 영상의 기법을 섞음)입니다.
저장한 카드는 훑기 좋게 격자로 나옵니다. 카드마다 종류 태그, ☆/★, 제목, 한 줄 요약, 근거 영상 썸네일 3개가 있고, 카드를 누르면 자세한 내용이 오른쪽 패널(폰과 좁은 화면은 아래에서 올라오는 시트)에 열립니다.

## 사용 예
1. 위쪽 "새 카드 주제 (선택)"에 예: 비 오는 날 실내 여행처럼 적습니다.
2. "새 카드 뽑기 · 약 30초"를 누릅니다. 기다리는 동안 화면을 계속 쓰거나 다른 화면으로 가도 됩니다. 진행은 머리말의 작업 상태 칩에 나오고, 끝나면 알림이 뜹니다.
3. 미리보기에서 제목·아이디어·찍는 법을 고치고, 저장할 카드만 체크해 "선택한 카드 저장"을 누릅니다. 저장하면서 ★도 달 수 있습니다.
4. 위의 칩(전체 / ★ / 흐름 / 기법 / 각도 / 조합, 개수 포함)으로 거르고, 카드의 ☆를 눌러 즐겨찾기합니다.
5. 카드를 누르면 상세에 설명, "이렇게 찍어 보세요" 단계, 근거 영상(썸네일과 제목 링크), "이 카드로 만든 영상"이 나옵니다. 빨간 "이 카드로 새 영상 시작"을 누르면 그 카드를 출처로 새 기획안 만들기가 열리고, 저장하면 새 영상이 내 영상에 생깁니다.

## 이렇게 나와요
```
[전체 22] [★ 3] [흐름 4] [기법 9] [각도 6] [조합 3]

[기법] ☆                     [흐름] ★
결과 선공개 탑뷰 오프닝        길 위의 여정 기록
완성된 라면을 첫 1초에…       출발 전 짐 싸기부터 숙소까지…
[썸][썸][썸] 근거 영상 3       [썸][썸] 근거 영상 2

(상세) 설명 / 이렇게 찍어 보세요 1. 0–1초 완성품 탑뷰 2. … / 근거 영상 / 이 카드로 만든 영상
       [이 카드로 새 영상 시작]
```

## 알아 둘 것
- 나오는 카드 종류는 레퍼런스 수로 정해집니다. 0~4개(1단계)는 기법만, 5~9개(2단계)는 기법·각도, 10개 이상(3단계)은 4종 모두입니다. 3단계여도 유형화 결과가 없으면(유형화를 실행하지 않았으면) 흐름·조합 카드는 나오지 않습니다. 저장 여부가 아니라 실행 결과가 있는지로 정해집니다. 아직 나올 수 없는 종류의 칩은 점선으로 보입니다.
- 카드는 근거가 되는 내 레퍼런스 영상이 반드시 붙습니다. 프로필이 없으면 카드가 일반적으로 나옵니다.
- 한 줄 요약은 따로 저장된 값이 없어 카드 아이디어의 첫 문장(최대 60자)을 씁니다. 근거 영상 썸네일은 레퍼런스 목록의 첫 장면 사진이고, 목록에 없는 영상은 회색 칸으로 보입니다.
- "이 카드로 만든 영상"은 지금 카테고리의 기획안 중 이 카드를 출처로 만든 것만 보입니다.
- 카드 뽑기는 Claude를 한 번 부르고 수십 초가 걸립니다. 미리보기에서는 아무것도 바뀌지 않고, 저장한 카드만 카테고리에 쌓입니다.
- "다시 뽑기"를 하면 미리보기에서 고친 내용은 사라지지만 저장한 카드는 그대로입니다.
