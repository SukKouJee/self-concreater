title: 공용 라이브러리
---
## 무엇을 하나요
지인들과 훅 기법과 기획안 틀을 나누는 공용 라이브러리 화면입니다. 이 서버에서는 아직 쓸 수 없습니다.

## 사용 예
1. 이 화면을 열면 "공용 라이브러리는 이 서버에서 아직 쓸 수 없습니다" 한 줄이 나옵니다.
2. 기법과 기획안 틀은 내 레퍼런스로 만듭니다. [모티브](#/motif)에서 카드를 뽑아 보세요.

## 이렇게 나와요
```
공용 라이브러리는 이 서버에서 아직 쓸 수 없습니다
```

## 알아 둘 것
- 모티브 카드와 기획안은 라이브러리 없이도 내 레퍼런스만으로 만들 수 있습니다.

- 재료를 늘리려면 [레퍼런스 넣기](#/add)
