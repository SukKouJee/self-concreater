## 무엇을 하나요
메뉴 영감 › **레퍼런스**(폰은 아래 "영감" 탭)에서 엽니다.
한 화면에서 영상을 넣고, 확인하고, 저장된 영상을 둘러봅니다. 위쪽 "+ 링크 추가"를 눌러 유튜브 링크를 붙여 넣으면 영상을 하나씩 분석해 영상별 분석 기록으로 만들고, 아래 목록에는 지금 카테고리에 저장된 영상이 카드로 나옵니다. 영상을 열면 요약·시놉시스·섹션 표·기법과 장면 프레임을 볼 수 있고, 분석이 틀렸을 때 섹션 라벨과 훅·서사 유형을 직접 고칠 수도 있습니다.
구분은 "레퍼런스"(따라 배울 영상) 또는 "내 영상"(진단할 내 영상) 중에서 고릅니다.

## 사용 예
1. "+ 링크 추가"를 눌러 펼칩니다(메뉴 대신 [레퍼런스 넣기](#/add)로 들어오면 처음부터 펼쳐져 있습니다). 제목에 "<카테고리> 카테고리에 넣습니다"가 나오고, 구분을 고릅니다.
2. 링크를 한 줄에 하나씩 붙여 넣습니다. 줄마다 상태가 바로 나옵니다: 새 영상 / 이미 있음 / 다른 구분으로 있음 / 중복 / 영상 링크 아님 / 다시 분석. 필요 없는 줄은 ×로 지웁니다.
3. "영상 N개 분석 시작"을 누릅니다. 분석 중에도 링크를 더 붙여 넣으면 대기열 뒤에 붙습니다.
4. 분석이 끝난 영상은 "확인 대기" 카드로 쌓입니다. 분석은 카드를 기다리지 않고 다음 영상으로 넘어갑니다. 카드에서 섹션 라벨을 고치고 "저장"하거나, "모두 저장"으로 한 번에 저장합니다.
5. 분석이 틀렸다면 "고칠 점 적고 다시 분석"으로 고칠 점을 적어 다시 요청합니다. 뺄 영상은 "건너뛰기"입니다.
6. 저장된 영상은 아래 목록에서 "레퍼런스 / 내 영상 / 전체" 칩으로 거르고, 제목·채널로 검색하거나 정렬(최근 추가순·길이순·제목순)을 바꿉니다. 카드를 눌러 상세를 열고 "라벨 고치기"로 고칩니다.

## 이렇게 나와요
링크를 붙여 넣으면 줄마다 이렇게 나옵니다.
```
https://youtu.be/AAAA…   새 영상            ×
https://youtu.be/BBBB…   이미 있음          ×
https://youtu.be/CCCC…   다른 구분으로 있음  ×
                          [영상 2개 분석 시작]
```
분석하는 동안에는 지금 분석 중인 영상 하나만 진행 카드로 나옵니다.
```
(42%)  약 2분 50초 남음 · 14:09쯤 끝          남은 영상 3개  [멈추기]
```
끝난 영상은 "확인 대기 N개"와 [모두 저장] 아래에 카드로 쌓입니다.
```
제목 · 길이 · 섹션 띠(훅 → 본문 → 아웃트로)
훅 질문형 · 서사 목록 · 형식 쇼츠
한 줄 요약
(경고가 있으면 한 줄)
[저장] [고칠 점 적고 다시 분석] [건너뛰기] [자세히]
```
"자세히"에는 섹션 표(라벨 고치기), 시놉시스, 기법이 나옵니다. 저장된 영상의 상세는 이렇습니다.
```
섹션 흐름: 훅 → 본문 → 아웃트로        [라벨 고치기]
(상세) 장면 프레임(0:12 · 훅 처럼 시각과 구간)
(상세) 한 줄 요약 / 시놉시스 / 섹션(분석 당시 기록) / 눈에 띄는 기법 / 내 메모
```
다른 카테고리에서 분석 중이면 "<카테고리> 카테고리에서 분석 중 · 확인 대기 N개 — 보기" 한 줄이 나옵니다.

## 알아 둘 것
- 영상은 하나씩 처리하고, 분석마다 Claude 호출이 일어나 시간이 걸립니다. 한 번에 한 카테고리만 분석하고, 다른 카테고리의 작업은 위 한 줄로 알려 줍니다.
- 이미 있는 영상은 다시 분석하지 않습니다. 다시 하려면 "고급"에서 "다시 분석"을 켭니다.
- "고급"에는 "자막·컷 새로 받기"와 "자막이 없을 때"(음성 인식 기본 / 화면만 보고 분석 / 건너뛰기)가 있습니다. 음성 인식은 시간이 오래 걸리고, 화면만 보고 분석하면 대사가 반영되지 않습니다. 요청이 늘면 차단되기 쉬워서 "새로 받기"는 꼭 필요할 때만 켜세요.
- "샷 분류도 함께"를 켜면 장면 사진으로 샷 크기·앵글도 분류하고, 콘티의 참고 장면에 쓰입니다. 샷 분류가 없는 영상이 있으면 목록 위에 "샷 분류 보강 (N개)" 버튼이 나오고, 그 영상들의 샷 분류만 채웁니다.
- 확인 대기 카드는 저장해야 기록됩니다. 저장하지 않은 결과는 서버가 다시 시작되면 사라져요. "모두 저장"은 라벨 수정을 그대로 저장하고, 저장에 실패한 카드는 이유와 함께 남습니다.
- 작업을 멈추면 "고칠 점 적고 다시 분석"은 쓸 수 없고 이유가 표시됩니다. 분석이 이어지는 동안에는 쓸 수 있습니다.
- 자막 수집이 차단되면 작업이 멈추고 남은 영상은 건너뜁니다.
- 영상 원본은 장면 사진을 뽑은 직후 지웁니다. 사진은 영상당 최대 40장입니다.
- 원 안의 숫자는 영상 하나 전체의 진행률(걸린 시간 기준)이고, 옆에 남은 시간과 끝날 시각이 나옵니다. 측정할 수 없는 단계(분석 등)가 예상을 넘기면 "예상보다 길어지는 중"이 뜨고, 원은 영상이 끝날 때까지 99%에서 멈춥니다. 예상은 이 서버에서 걸린 시간이 쌓일수록 정확해지며, 기록에는 시간과 길이 같은 숫자만 남습니다.
- 고칠 수 있는 것은 섹션 라벨(본문 세부 유형 포함)과 훅·서사 유형입니다. 저장하면 분석 기록의 앞부분(라벨·유형 칸)만 바뀌고 본문은 그대로입니다. 고친 영상에는 "직접 고침" 표시가 붙고, 레퍼런스를 고치면 다음 분석 때 교정 예시로 쓰입니다.
- 상세의 본문 섹션 표는 분석 당시 기록 그대로라 라벨을 고쳐도 바뀌지 않고, 위쪽 섹션 목록이 기준이 됩니다. 화면을 연 뒤 다른 창에서 기록이 바뀌었다면 저장이 거부되고 다시 불러오라고 안내합니다.
- 고친 라벨은 다음 유형화 때 반영됩니다. 유형화가 이상하면 여기서 라벨부터 확인하세요.
- 상세 아래의 "레퍼런스 삭제"(내 영상이면 "내 영상 삭제")는 영상 분석 기록과 분석 데이터(프레임·컷·샷 분류·자막)를 휴지통으로 옮기고, 기법 모음에서 그 영상 출처를 뺍니다. 다른 카테고리에 같은 영상이 있으면 분석 데이터는 그대로 둡니다. 잘못 지웠으면 관리자에게 문의하세요(지운 것은 휴지통에 보관됩니다). 되살려도 기법 모음의 출처는 돌아오지 않습니다. 유형화에 들어간 영상이면 유형화를 다시 해야 결과에서 빠지고, 이미 뽑은 모티브 카드의 근거 링크는 그대로 남습니다. 수집이 돌고 있거나 그 카테고리에서 유형화가 진행 중이면 삭제할 수 없습니다.
