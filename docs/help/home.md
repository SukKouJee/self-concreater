## 무엇을 하나요
카테고리별로 지금 어디까지 왔는지 한눈에 보는 화면입니다. 카드마다 진행 단계(모으기 → 유형화 → 기획안 → 콘티 → 진단)가 표시되고, 다음에 할 일과 그 화면으로 가는 버튼이 나옵니다.
아래에는 오늘 미션 상태와 최근에 만든 결과물(기획안·콘티·리포트, 최대 5개)이 있습니다.
화면 위쪽에서 고른 카테고리의 카드가 맨 위에 옵니다.

## 사용 예
1. 작업을 시작할 때 홈을 열어 카드의 "다음 할 일" 문장을 읽습니다.
2. 카드의 "열기" 버튼으로 해당 화면으로 갑니다.
3. 작업 폴더를 처음 열었다면 "이 폴더를 yt-coach 작업 폴더로 만들기" 버튼이 나옵니다. 누르면 폴더가 만들어집니다.

## 이렇게 나와요
```
먹방
- ref: 3개 / mine: 0개
- 현재 단계: 1 (0~4개) — 영상별 분석, 기법 카탈로그, 기법 모티브
- 다음 단계까지: ref 2개 더 (5개부터 예비 관찰)
[ 모으기 ] [ 유형화 ] [ 기획안 ] [ 콘티 ] [ 진단 ]
다음 할 일: 레퍼런스 2개 더 모으면 유형화를 할 수 있어요
```

## 알아 둘 것
- 단계 표시는 파일을 읽어서 계산하며, 홈에서는 아무것도 바꾸지 않습니다.
- 완료 기준: 모으기는 레퍼런스 5개 이상, 유형화는 유형화 결과를 저장했을 때, 기획안·콘티·진단은 각각 1개 이상 있을 때입니다.
- 카테고리가 하나도 없으면 터미널에서 `/yt-coach:yt-init`으로 첫 카테고리를 만들라는 안내가 나옵니다.
- 모티브·다듬기·자막 영상·미션 진행은 단계 표시에 들어 있지 않습니다(미션은 별도 카드로 보입니다).
