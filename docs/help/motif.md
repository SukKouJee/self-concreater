## 무엇을 하나요
내 레퍼런스를 바탕으로 "무엇을 어떤 흐름으로 찍을지" 아이디어 카드를 뽑아 줍니다. 카드는 네 종류입니다. 기법(떼어 쓸 수 있는 훅·전환·엔딩·촬영 한 가지), 각도(레퍼런스가 덜 다룬 주제나 관점), 흐름(아키타입 골격을 내 주제에 적용), 조합(구조와 서로 다른 영상의 기법을 섞음)입니다.
뽑은 카드는 미리보기에서 고쳐서 골라 저장하고, 저장한 카드에서 바로 기획안을 만들 수 있습니다.

## 사용 예
1. 필요하면 "주제(선택)"에 예: 편의점 라면처럼 적습니다. 공용 라이브러리에서 받은 지인 기법을 재료로 더할 수도 있습니다(최대 10개).
2. "새 카드 뽑기"를 누르고 기다립니다.
3. 미리보기에서 제목·아이디어·찍는 법을 고치고, 저장할 카드만 체크해 "선택한 카드 저장"을 누릅니다. 저장하면서 ★도 달 수 있습니다.
4. 저장한 카드 목록에서 종류별로 거르거나 ★로 즐겨찾기하고, "기획안 만들기"를 누르면 그 카드를 출처로 기획안 화면이 열립니다.

## 이렇게 나와요
```
M-mukbang-001 · 기법 · 결과 선공개 탑뷰 오프닝
- 아이디어: 완성된 라면을 첫 1초에 탑뷰로 꽉 채워 보여 주고 시작
- 이렇게: 0–1초 완성품 탑뷰 → 1–3초 젓가락으로 한 입 → 3초 제목 자막
- 근거: [n6_YTMx9288](videos/n6_YTMx9288.md) 매운맛 5단계 챌린지 먹방
- 만든 날: 2026-10-25
```

## 알아 둘 것
- 나오는 카드 종류는 레퍼런스 수로 정해집니다. 0~4개(1단계)는 기법만, 5~9개(2단계)는 기법·각도, 10개 이상(3단계)은 4종 모두입니다. 3단계여도 유형화 결과가 없으면(유형화를 실행하지 않았으면) 흐름·조합 카드는 나오지 않습니다. 저장 여부가 아니라 실행 결과가 있는지로 정해집니다.
- 카드는 근거가 되는 내 레퍼런스 영상이 반드시 붙습니다. 프로필이 없으면 카드가 일반적으로 나옵니다.
- 카드 뽑기는 Claude를 한 번 부르고 수십 초가 걸립니다. 미리보기에서는 파일이 바뀌지 않고, 저장한 카드만 카테고리의 index.md에 쌓입니다.
- "다시 뽑기"를 하면 미리보기에서 고친 내용은 사라지지만 저장한 카드는 그대로입니다.
- 기법 카탈로그에서 같은 기법을 합치는 정리는 화면에는 없고 터미널 `/yt-coach:yt-inspire`에서 합니다.
