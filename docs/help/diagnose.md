## 무엇을 하나요
내 영상이나 기획안이 레퍼런스에서 뽑은 아키타입과 얼마나 비슷한지 축별로 비교합니다. 가장 가까운 아키타입, 축별 근접도(구조·훅·서사·제목·컷 속도), 아키타입과 눈에 띄게 다른 지점(갭)이 나옵니다. 하나의 종합 점수는 없습니다.
Claude가 갭 설명과 다음에 할 행동 1~3개를 써 주고, 일부러 다르게 한 갭은 표시해서 이후 진단에서 뺄 수 있습니다.

## 사용 예
1. 목록의 "내 영상"(레퍼런스 추가에서 구분을 "내 영상"으로 넣은 것) 또는 "기획안"에서 대상을 고릅니다.
2. "비교하기"를 누르면 바로 결과가 나옵니다(Claude 없음).
3. "설명 받기"를 누르면 요약·갭 설명·다음 행동이 나옵니다. 고친 뒤 "저장"하면 `mine/<이름>.md`에 기록됩니다.
4. 저장한 진단에서 갭마다 "일부러 다르게 한 거예요"를 누르면 바로 저장되고, 이후 진단과 미션 재료에서 빠집니다.

## 이렇게 나와요
```
진단: 컵라면 4단계 도전 — 가장 가까운 아키타입 A1 결과 먼저 몰아먹기
축별 근접도: structure 29% · hook 75% · narrative 25% · title 50% · pacing 80%
갭: structure:intro (나 33% / 아키타입 1%)
요약: 인트로가 길고 본론이 짧아 구조 근접도는 낮다.
다음 행동: 1. 인트로 20초를 5초 안으로 줄이고 첫 화면에 완성품을 둔다
```

## 알아 둘 것
- 비교할 아키타입이 있어야 합니다. 유형화 결과가 없으면 비교할 수 없다는 안내가 나옵니다.
- 마지막으로 유형화를 실행했을 때 레퍼런스가 10개 미만이었으면 "예비 진단"으로 표시되고 참고용으로만 봐야 합니다. 지금 10개를 넘었어도 유형화를 다시 실행해야 정식 진단이 됩니다.
- 비교하기는 바로 끝나고, 설명 받기는 Claude를 한 번 부르며 수십 초가 걸립니다. 저장하기 전에는 파일이 바뀌지 않습니다.
- 저장한 뒤 갭이 바뀌면 저장된 설명이 지금 갭과 다르다고 알려 주고 설명 다시 받기를 권합니다.
- 진단은 아키타입을 바꾸지 않고, 아키타입도 내 영상을 기준에 섞지 않습니다.
- 내 영상이나 기획안이 없으면 목록이 비어 있고 추가하러 가는 링크가 나옵니다. 대본 붙여넣기나 링크 바로 진단은 화면에 없고 터미널 `/yt-coach:yt-diagnose`로 합니다.
