## 무엇을 하나요
처음부터 끝까지 영상 하나를 만드는 순서를 단계 목록으로 보여 줍니다. 위쪽 탭은 "숏폼 만들기"와 "롱폼 만들기" 두 개이고, 기본은 숏폼입니다.
각 단계에는 해당 화면으로 가는 링크, 그 단계에서 할 일, 만들어지는 것이 한 줄씩 적혀 있습니다.

## 사용 예
1. 처음 쓴다면 숏폼 탭의 1단계부터 차례로 따라갑니다.
2. 단계 링크를 누르면 그 화면으로 이동하고, 도움말 패널과 가이드를 오가며 볼 수 있습니다.
3. 롱폼을 만들 때는 롱폼 탭에서 숏폼과 달라지는 점만 확인합니다.

## 이렇게 나와요
```
1. 레퍼런스 넣기 → 할 일: 링크를 붙여 분석 → 만들어지는 것: 영상별 md
2. 유형화       → 할 일: 실행하고 근거·이름 확인 → 만들어지는 것: 판정과 아키타입
…
```

## 알아 둘 것
- 단계 옆의 완료 표시는 지금 고른 카테고리의 진행 상황(레퍼런스 모으기, 유형화, 기획안, 콘티, 진단)을 따릅니다. 모티브, 다듬기, 자막 영상, 미션은 완료 표시가 없습니다.
- 가이드는 읽는 화면이라 여기서 파일이 바뀌지 않습니다.
- 모든 Claude 작업은 미리보기를 확인하고 저장해야 기록됩니다.
- 숏폼과 롱폼의 차이는 길이 기준(180초)과 화면 비율 정도이고, 나머지 흐름은 같습니다.
