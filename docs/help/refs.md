## 무엇을 하나요
지금 카테고리에 저장된 영상을 카드로 보여 줍니다. 카드에는 섹션 흐름 띠, 훅·서사 유형 등이 있고, 영상을 열면 요약·시놉시스·섹션 표·기법과 장면 프레임, md 파일 경로를 볼 수 있습니다.
분석이 틀렸을 때 섹션 라벨과 훅·서사 유형을 직접 고칠 수 있는 화면이기도 합니다.

## 사용 예
1. 위쪽에서 "레퍼런스 / 내 영상 / 전체"로 거르고, 제목·채널로 검색하거나 정렬(최근 추가순·길이순·제목순)을 바꿉니다.
2. 영상 카드를 눌러 상세를 엽니다.
3. "라벨 고치기"를 눌러 섹션 라벨과 훅·서사 유형을 바꾸고 "저장"합니다.

## 이렇게 나와요
```
섹션 흐름: hook → body → outro        [직접 고침]
훅 question · 서사 list · 형식 shorts
(상세) 한 줄 요약 / 시놉시스 / 섹션 / 눈에 띄는 기법
(상세) 장면 프레임, md 파일 경로 [경로 복사]
```

## 알아 둘 것
- 고칠 수 있는 것은 섹션 라벨(본문 세부 유형 포함)과 훅·서사 유형입니다. 저장하면 md 앞부분(프런트매터)만 바뀌고 본문은 그대로입니다.
- 고친 영상에는 "직접 고침" 표시가 붙습니다. 레퍼런스를 고치면 다음 분석 때 교정 예시로 쓰입니다.
- 상세의 본문 섹션 표는 분석 당시 기록 그대로라 라벨을 고쳐도 바뀌지 않고, 위쪽 섹션 목록이 기준이 됩니다.
- 화면을 연 뒤 다른 곳에서 md가 바뀌었다면 저장이 거부되고 다시 불러오라고 안내합니다.
- 고친 라벨은 다음 유형화 때 반영됩니다. 유형화가 이상하면 여기서 라벨부터 확인하세요.
- 상세 아래의 "레퍼런스 삭제"(내 영상이면 "내 영상 삭제")는 영상 md와 분석 데이터(프레임·컷·샷 분류·자막)를 `workspace/trash/<시각>/` 폴더로 같은 경로 그대로 옮기고, 기법 모음(`techniques.md`)에서 그 영상 출처를 뺍니다. 다른 카테고리에 같은 영상이 있으면 분석 데이터는 그대로 둡니다. 잘못 지웠으면 그 폴더 안의 파일을 같은 경로로 다시 옮기면 되지만, 기법 모음의 출처는 돌아오지 않습니다. 유형화에 들어간 영상이면 유형화를 다시 해야 결과에서 빠지고, 이미 뽑은 모티브 카드의 근거 링크는 그대로 남습니다. 레퍼런스 수집이 돌고 있거나 그 카테고리에서 유형화가 진행 중이면 삭제할 수 없습니다.
