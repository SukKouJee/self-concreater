## 무엇을 하나요
탭이 두 개 있습니다. "카테고리 리포트"는 카테고리의 분석 결과를 한 장짜리 HTML 문서로 만들어 줍니다(축별 판정, 아키타입 비교, 컷 길이 분포, 진단 추이).
"주간 회고"는 한 주의 미션 완료율·종류·난이도, 건너뛴 사유, 새 모티브 카드, 진단 갭을 모아 보여 주고, 그 주를 돌아보는 회고를 쓰게 도와줍니다.

## 사용 예
1. 카테고리 리포트: "리포트 만들기"를 누르면 `reports/` 폴더에 날짜가 붙은 HTML이 생기고, 목록에서 "보기"로 화면 안에서 열거나 "새 탭에서 열기"로 엽니다.
2. 주간 회고: 주를 고르면 숫자가 바로 나옵니다. "회고 쓰기"로 요약·반복된 약점·다음 주 방향·프로필 변경 제안을 받아 고치고 "저장"합니다.
3. 저장한 회고에서 프로필 변경 제안을 체크하고 "체크한 항목을 프로필에 반영"을 누르면 선택한 항목만 profile.md에 반영됩니다.

## 이렇게 나와요
```
2026-W43 주간 회고
이번 주 숫자: 5개 중 4개 제출(80%)
종류 촬영 3개 · 난이도 적당 2개 · 건너뛴 사유 시간 부족
새 모티브 카드 3장 · 진단 갭 2개
회고: 요약 / 반복된 약점 / 다음 주 방향 / 프로필 변경 제안
```

## 알아 둘 것
- 리포트 만들기는 Claude 없이 지금 기록으로 만들어서 바로 끝납니다. 유형화 결과가 없으면 리포트가 채워지지 않으니 먼저 유형화를 하세요.
- 리포트는 스크립트 실행이 막힌 프레임 안에서 보여 줍니다.
- 회고 쓰기는 Claude를 한 번 부르고, 저장하기 전에는 파일이 바뀌지 않습니다. 저장하면 `reviews/<주>.md`가 만들어지고, 직접 쓴 `## 내 메모`는 유지됩니다.
- 회고를 쓰거나 고치는 동안에는 주를 바꿀 수 없습니다.
- 프로필 반영은 체크한 항목만, 눌러야만 바뀝니다. 프로필이 없으면 반영할 수 없습니다.
