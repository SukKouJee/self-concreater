## 무엇을 하나요
유튜브 링크를 붙여 넣으면 영상을 하나씩 분석해서 영상별 md 파일로 저장합니다. 자막·장면 컷을 모으고, Claude가 섹션 구성·훅 유형·서사 유형·기법을 분석합니다.
분석 결과는 바로 저장되지 않고 확인 카드로 먼저 보여 줍니다. 구분은 "레퍼런스"(따라 배울 영상) 또는 "내 영상"(진단할 내 영상) 중에서 고릅니다.

## 사용 예
1. 카테고리를 고르고, 구분에서 "레퍼런스"를 선택합니다.
2. 링크를 한 줄에 하나씩 붙여 넣고 "추가 시작"을 누릅니다.
3. 영상마다 확인 카드가 나오면 섹션 라벨을 필요한 만큼 고치고 "저장"을 누릅니다. 이 영상은 빼려면 "건너뛰기"입니다.
4. 분석이 틀렸다면 "고칠 점 입력 후 다시 분석"으로 고칠 점을 적어 다시 요청할 수 있습니다.

## 이렇게 나와요
확인 카드에 이런 내용이 나옵니다.
```
요약: 컵라면 4종을 맵기 순서대로 먹는 도전 영상
훅 question · 서사 list
섹션 타임라인: hook 0:00–0:02 / body 0:02–0:40 / outro 0:40–0:45
기법: [훅] 결과 선공개 — 0:00 …
프레임: 장면 사진 여러 장
[저장] [남은 영상 모두 저장] [건너뛰기] [고칠 점 입력 후 다시 분석]
```
분석하는 동안에는 영상마다 맨 위에 전체 진행이 크게 나오고, 그 아래에 단계 칸이 작게 나란히 붙습니다.
```
(42%)  약 2분 50초 남음 · 14:09쯤 끝
       지금: 컷 — 카메라 움직임 확인 중 (300 / 508 장면) · 이 단계 약 20초 남음
자막 ✓ 0:38 | 컷 62% | 분석 ~1:30 | 샷 분류 ~1:00
걸린 시간 2:02 · 예상 전체 4:53
```
단계 칸의 폭은 그 단계에 걸리는(걸릴) 시간에 맞춰 넓어집니다. 차례를 기다리는 영상에는 "앞 영상이 끝나면 시작해요"가 나옵니다.

## 알아 둘 것
- 영상은 하나씩 처리하고, 분석마다 Claude 호출이 일어나 시간이 걸립니다.
- 이미 분석한 영상은 다시 분석하지 않습니다. 다시 하려면 "이미 분석한 영상도 다시 분석"을 켭니다.
- 자막이 없으면 음성 인식(STT), 화면만 보고 분석, 건너뛰기 중에서 고릅니다. 음성 인식은 시간이 오래 걸리고, 화면 분석은 대사가 반영되지 않습니다.
- "샷 분류도 함께"를 켜면 장면 사진으로 샷 크기·앵글도 분류하고, 콘티의 참고 장면에 쓰입니다. 이미 있는 영상의 샷 분류만 채우려면 "샷 분류만 보강"을 누릅니다.
- 자막 수집이 차단되면 작업이 멈추고 남은 영상은 건너뜁니다. 요청이 늘면 차단되기 쉬워서 "자막·컷을 새로 받기"는 꼭 필요할 때만 켜세요.
- 영상 원본은 장면 사진을 뽑은 직후 지웁니다. 사진은 영상당 최대 40장입니다.
- 원 안의 숫자는 영상 하나 전체의 진행률(걸린 시간 기준)이고, 옆에 전체 남은 시간과 끝날 시각이 나옵니다. 단계 칸에 마우스를 올리면(화면 읽기 프로그램은 바로 읽어 줍니다) 그 단계의 걸린 시간과 처음 예상이 보입니다. 측정할 수 없는 단계(분석 등)가 예상을 넘기면 남은 시간 대신 "예상보다 길어지는 중 · 곧 끝날 예정"이 나오고, 원은 영상이 끝날 때까지 99%에서 멈춥니다. 확인 카드를 기다린 시간과 차단 방지 대기는 남은 시간에 넣지 않습니다. 예상보다 길어지면 주황색 "예상보다 길어지는 중"이 뜹니다.
- 예상은 처음엔 대략적인 값이고, 이 PC에서 걸린 시간이 쌓일수록 정확해집니다. 기록에는 걸린 시간과 영상 길이 같은 숫자만 남고 제목·링크·내용은 남지 않습니다.
- 끝나면 저장·건너뜀·실패 개수와 현재 단계 안내가 나옵니다.
