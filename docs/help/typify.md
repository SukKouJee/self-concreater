## 무엇을 하나요
메뉴 영감 › **유형**(폰은 아래 "영감" 탭 위쪽 링크)에서 엽니다. 카테고리의 레퍼런스 영상을 비교해서 영상들이 어떤 틀로 갈라지는지 알려 줍니다. 구조, 훅, 서사, 제목, 컷 속도 같은 축마다 "유형 있음 / 약한 경향 / 유형 없음 / 데이터 부족" 판정과 근거 문장을 붙이고, 비슷한 영상 묶음에는 아키타입(대표 유형)을 만들어 이름을 제안합니다.
기준에는 레퍼런스만 쓰고, 내 영상은 섞지 않습니다. 이렇게 판정하는 일을 "유형화"라고 부릅니다.

## 사용 예
1. 레퍼런스가 5개 이상이면 "유형화 실행"을 누릅니다.
2. 몇십 초 뒤 미리보기에 축별 판정 표, 아키타입 카드, 이상치(혼자 떨어진 영상)가 나옵니다.
3. 근거 문장과 아키타입 이름을 고친 뒤 "저장"하면 기록됩니다. 사이드바 "유형" 옆 숫자는 저장한 아키타입 수입니다.
4. 다시 하려면 "다시 실행"입니다.

## 이렇게 나와요
```
레퍼런스 12개 · 정식 판정 · 마지막 유형화 2026-10-23
| 축   | 판정      | 영상/묶음    | 근거                                              |
| 구조 | 유형 있음 | 12개 · 3묶음 | 12개 중 8개가 '짧은 훅 → 긴 본론 → 구독 요청' 골격 |
| 서사 | 유형 없음 | 12개 · 4묶음 | 리스트 4 · 여정 3 · 반응 3 · 비교 2로 갈림         |
아키타입: A1 결과 먼저 몰아먹기 (5개)  훅 → 인트로 → 본문(이야기) → 아웃트로
```

## 알아 둘 것
- 단계 기준: 레퍼런스 4개까지는 유형을 볼 수 없고(실행 버튼 없음), 5~9개는 "예비 관찰", 10개부터 "정식 판정"입니다. 예비 관찰의 문장은 단정하지 않는 표현으로 나옵니다.
- 실행은 Claude를 한 번 부르고 수십 초가 걸립니다. 미리보기 단계에서는 아무것도 바뀌지 않고, 저장해야 기록됩니다. 다른 화면으로 가면 고친 내용이 사라집니다.
- 아키타입은 구조가 비슷한 영상이 2개 이상 모여야 생기고, 이름은 제안일 뿐이라 직접 확정합니다. 아키타입이 없으면 이후 진단 비교도 할 수 없습니다.
- 판정이 이상하면 [레퍼런스](#/refs)에서 영상 라벨을 고친 뒤 다시 실행하세요. 다시 실행해도 같은 축·아키타입이 있으면 고친 근거·이름은 유지됩니다.
- 모티브의 흐름·조합 카드는 이 결과가 있어야 나옵니다.
