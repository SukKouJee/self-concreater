## 무엇을 하나요
하루 15~30분 안에 끝낼 수 있는 오늘의 미션을 줍니다. ★ 모티브 카드, 최근 기획안, 진단 갭, 지난 기록을 재료로 쓰고, 프로필의 성장 단계(관찰 → 모방 → 제작 → 변형)에 맞춰 만듭니다.
완료 제출, 건너뛰기, 바꾸기를 이 화면에서 하고, 최근 14일 기록과 이번 주 완료율도 보여 줍니다.

## 사용 예
1. "오늘 미션 받기"를 누르면 미리보기가 나옵니다. 마음에 들면 "이걸로 할게요", 아니면 "다른 걸로"를 누릅니다.
2. 미션을 마치면 "완료 제출"에서 한 일(300자까지)과 난이도(쉬움·적당·어려움)를 적고, 원하면 사진·스크린샷·텍스트 파일 경로를 넣습니다. "피드백 받기"로 받은 피드백을 고쳐 저장합니다.
3. 못 하겠으면 "건너뛰기"에서 이유(시간 부족, 재료 없음, 하기 싫음, 기타)를 고릅니다.
4. 마음에 안 들면 "바꾸기"로 다른 재료의 미션 미리보기를 받아 교체합니다.

## 이렇게 나와요
```
탑뷰 손 클로즈업 15초 찍기   [촬영] [20분]
왜: ★카드 '편의점 컵라면 맵기 4단계'의 핵심 샷을 먼저 연습한다
단계: 1. 폰을 그릇 위 탑뷰로 고정 2. 면을 들어 올리는 손만 15초 원컷 3. 같은 샷을 2번 더
결과물: 15초 클립 3개 중 가장 나은 1개
```

## 알아 둘 것
- 오늘 미션은 하루에 하나가 저장됩니다. 미션 받기, 피드백 받기, 바꾸기는 각각 Claude를 한 번 부르고 수십 초가 걸리며, 저장하기 전에는 기록이 바뀌지 않습니다.
- 미션 시간은 프로필의 하루 시간에서 시작해 15~30분 사이입니다. 최근 끝난 미션 3개 중 어려움·건너뜀이 2개 이상이면 5분 줄이고, 쉬움이 2개 이상이면 5분 늘립니다.
- 프로필이 없으면 맞춤이 아닌 일반 미션이 나옵니다. 프로필은 터미널 `/yt-coach:yt-init`으로 만듭니다.
- 제출 파일은 이미지(png·jpg·webp·gif)와 텍스트(txt·md)만, 10MB까지입니다. 원본은 건드리지 않고 잠깐 복사해 읽은 뒤 지웁니다. 영상은 설명으로 적어 주세요.
- 이미 완료한 미션을 다시 제출하면 이전 제출을 덮어씁니다.
- 날짜가 바뀌면 새로 불러오라는 안내가 나옵니다.
