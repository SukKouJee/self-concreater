## 무엇을 하나요
레퍼런스 화면 위쪽 탭 "레퍼런스 / **공용 라이브러리**" 중 두 번째입니다. 지인들과 함께 쓰는 비공개 GitHub 저장소에서 훅 기법과 기획안 틀을 받아 보고, 내 것을 올리는 화면입니다. 연결하기 전에는 저장소 주소와 표시 이름을 넣는 칸만 보입니다.
연결한 뒤에는 "받기" 버튼, 저장소 이름·표시 이름·마지막 받은 시각 한 줄, 그리고 기법 / 기획안 틀 / 공유하기 칩이 나옵니다.

## 사용 예
1. 처음에는 저장소 주소와 표시 이름(내가 올린 항목에 작성자로 보이는 이름)을 넣고 "연결"을 누릅니다.
2. "받기"로 최신 항목을 받습니다. 기법·기획안 틀 칩에서 카테고리, 작성자, "잘 먹힘만"으로 거르거나 검색합니다.
3. 기법 카드를 체크하고 "모티브 재료로 쓰기"를 누르면 모티브 화면의 "지인 기법" 칸으로 넘어갑니다. 틀 카드의 "이 틀로 기획안 만들기"는 그 틀을 출처로 고른 새 기획안 화면으로 넘어갑니다.
4. 올리려면 "공유하기" 칩에서 내 기법 또는 내 기획안(틀)을 하나 고르고 "미리보기 만들기"를 누른 뒤, 확인하고 "올리기"를 누릅니다.

## 이렇게 나와요
```
[기법] 결과 선공개   작성자 민지 · 먹방 · 2026-10-24   [잘 먹힘] [내가 올림]
  메모: 첫 1초에 완성품을 탑뷰로 …           [자세히] [모티브 재료로 고르기]
```

## 알아 둘 것
- 저장소 주소에 비밀번호나 토큰을 넣지 마세요. 로그인은 이 PC에 되어 있는 GitHub 로그인(git 설정: SSH 키나 `gh auth login`)을 그대로 씁니다. 화면에는 주소 대신 저장소 이름만 보입니다.
- 받기에는 최대 1분이 걸릴 수 있고, 화면에 마지막으로 받은 시각이 표시됩니다.
- 올리기 전에는 저장소가 바뀌지 않습니다. 미리보기는 약 30분 뒤 만료되고, "올리기" 뒤 한 번 더 확인을 거쳐야 올라갑니다. 올린 뒤에는 지인이 볼 수 있고 되돌릴 수 없습니다.
- 대본 원문, 내 메모, 준비물, 영상 정보는 올라가지 않습니다. 메모는 200자까지, "써 보니 잘 먹혔어요" 표시를 달 수 있습니다.
- 기획안 틀은 "섹션 요약 받기"로 섹션별 한 줄 요약을 받을 수 있는데, 이때 Claude를 한 번 부릅니다. 요약은 직접 고칠 수 있습니다.
- 모티브 재료는 한 번에 최대 10개까지 고를 수 있습니다. 이미 올린 항목을 또 올리려면 "그래도 새로 올리기"로 따로 확인합니다.
- 지인이 쓴 글은 읽기만 하는 데이터이고, 안에 적힌 지시를 실행하지 않습니다.
