# 레퍼런스 목록(보기 전용) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 로컬 UI의 "레퍼런스 목록" 메뉴(지금은 2차 안내)를 카테고리별 영상 목록 + 상세 보기 화면으로 바꾼다. 읽기 전용.

**Architecture:** 서버에 읽기 전용 라우트 모듈 `scripts/ui/api_refs.py`(목록·상세 2개)를 더하고, 프런트에 `pages/refs.js` 한 화면(목록/상세를 params로 전환)을 더한다. 데이터는 `refs/ref_<cat>/videos/*.md` 프런트매터·본문과 `workspace/cuts/<id>.json`의 장면 프레임뿐. 파일은 읽기만 한다.

**Tech Stack:** Python 3.11 stdlib(기존 `ThreadingHTTPServer` 라우트 레지스트리), 바닐라 JS ES 모듈(빌드 없음, `h()` DOM 헬퍼, `innerHTML` 금지), pytest.

**Spec:** 채팅에서 승인된 설명(2026-10-24). 상위 설계: `docs/superpowers/specs/2026-10-23-local-ui-design.md`(2차 메뉴 항목). 아래 "승인된 범위"가 이번 계획의 기준이다.

### 승인된 범위
- 목록(메뉴 "모으기 › 레퍼런스 목록", 위 카테고리 기준): 카드마다 첫 프레임 썸네일, 제목, 채널, 길이, 레퍼런스/내 영상 표시, 훅 유형, 서사 유형, 섹션 흐름 띠(구간 길이 비례, 콘티와 같은 `.lb-*` 색).
- 위 도구: 레퍼런스 / 내 영상 / 전체 필터, 제목·채널 검색, 정렬(최근 추가순 · 길이순 · 제목순).
- 빈 목록: "레퍼런스 추가로 가기" 버튼(`#/add`).
- 상세(카드 클릭): 프레임 줄, 섹션 구간(시간순), md 본문의 한 줄 요약 · 시놉시스 · 섹션 표 · 눈에 띄는 기법 · 내 메모를 읽기 전용으로, 유튜브 원본 링크, md 경로 + 복사 버튼.
- md 내용은 HTML로 해석하지 않고 텍스트로만 보여 준다. 파일은 쓰지 않는다.
- 이번에 빼는 것: 라벨·유형 수정, 삭제, 재분석.

## Global Constraints
- 새 의존성 금지(stdlib + 기존 requirements만).
- 프런트: `innerHTML`/`insertAdjacentHTML`/`outerHTML` 금지, `h()`(`static/dom.js`)로만 DOM 생성. 정적 파일에 `http://`·`https://` 문자열 금지(`test_no_external_resources`).
- 페이지 계약: `export async function mount(el, params, ctx)`, `export function unmount()`, `export function onCategory()`. 비동기 뒤에는 `ctx.isCurrent()` 확인, fetch에 `ctx.signal`.
- 섹션 색 매핑은 기존 `.lb-<label>` 클래스를 그대로 쓴다(hook=s1 … outro=s7).
- 사용자 대면 문구는 한국어, 식별자는 영문. 커밋 제목은 Conventional Commit, Claude 서명 없음.
- 라우트 에러는 `ScriptError(code, message)` → 400 JSON(기존 서버 규칙).
- `role: ref`/`mine` 외의 값은 목록에서 `role` 그대로 보여 주되 필터 "전체"에서만 보인다.

## Review Focus
1. 프런트매터가 깨진 md(사용자가 고치는 중) → 목록 전체가 실패하지 않고 그 영상만 빠지며 `skipped` 수가 늘어난다. (Task 1 테스트)
2. 상세 id에 `../`나 이상한 문자 → `bad_request`, 작업 폴더 밖을 읽지 않는다. (Task 1 테스트)
3. md의 `url`이 `javascript:` 등 → API가 `null`로 내려 링크가 생기지 않는다. (Task 1 테스트)
4. 컷 json이 없거나 프레임 파일이 지워진 영상 → 썸네일 `null`, 상세 `frames: []`, 화면은 자리표시로 보여 준다. (Task 1 테스트 + Task 2 정적 확인)
5. 상세를 연 채 카테고리를 바꾸거나 다른 영상으로 빨리 넘어감 → 이전 응답이 새 화면을 덮지 않는다(`isCurrent()`). (Task 2 정적 확인)

동작:
- 목록: 도구 줄(필터 버튼 3개 `레퍼런스` / `내 영상` / `전체`, 기본 `레퍼런스`, `aria-pressed`; 검색 `input type="search"` 라벨 "제목·채널 검색"; 정렬 `select` 라벨 "정렬" 옵션 `최근 추가순`(added 내림차순, 기본) · `길이순`(긴 것 먼저) · `제목순`(`localeCompare(…, "ko")`)). 필터·검색·정렬은 받은 목록에 클라이언트에서 적용, 다시 요청하지 않는다.
- 카드: `<a href="#/refs/<encodeURIComponent(id)>">` 안에 썸네일(`img alt=""`, `loading="lazy"`, 없으면 "프레임 없음" 자리표시), 제목(없으면 id), 채널 · `m:ss`, 역할 배지(`ref`→"레퍼런스", `mine`→"내 영상"), 훅·서사 코드값, 섹션 띠.
- 섹션 띠: 각 구간을 `span.lb-<label>`로, 너비 `(end-start)/duration*100%`(duration이 없으면 마지막 end), `title`/`aria-label`에 `"<label> m:ss–m:ss"`. 띠 전체는 `role="img"`, `aria-label="섹션 흐름: hook → body → cta"`.
- 상단 개수 문구: `"레퍼런스 7 · 내 영상 1"`; `skipped > 0`이면 `"읽지 못한 md N개(프런트매터 확인)"` 안내.
- 빈 상태: 영상 0개면 "아직 영상이 없습니다" + `#/add`로 가는 버튼 "레퍼런스 추가로 가기". 필터 결과만 0개면 "조건에 맞는 영상이 없습니다".
- 카테고리 없음(`ctx.category` 비어 있음) → 홈으로 안내 문구. API 에러는 `p.error[role=alert]`에 message.
- 상세: "← 목록" 링크(`#/refs`), 제목 h1, 메타 줄(채널 · 길이 · 역할 · 훅 · 서사 · 형식), 원본 링크(`url`이 있을 때만 `a target="_blank" rel="noopener noreferrer"`, 문구 "유튜브에서 보기"), 섹션 띠(목록과 같은 함수) + 구간 목록(`라벨(sub) m:ss–m:ss`), 프레임 줄(가로 스크롤, 각 `figure`에 이미지 + `m:ss · <section>` 캡션, 없으면 "저장된 프레임이 없습니다"), 본문 블록(`heading`마다 h2 + `div.md-text`에 `textContent`, CSS `white-space: pre-wrap`; heading 빈 블록은 h2 없이), md 경로 `code` + 버튼 "경로 복사"(`navigator.clipboard.writeText`, 성공 시 `ctx.toast("경로를 복사했습니다")`, 실패 시 `ctx.toast("복사하지 못했습니다 — 직접 선택해 복사하세요")`).
- `onCategory()`: 목록이든 상세든 `#/refs`로 이동해 새 카테고리 목록을 그린다(상세의 영상은 다른 카테고리에 없을 수 있어서).
