# 유형화 화면 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 로컬 UI의 "분석 › 유형화"(지금 2차 안내)를 실제 화면으로 만든다: 실행(계산 + Claude 해석) → 미리보기에서 근거 문장·아키타입 이름 고치기 → 저장(`index.md`).

**Architecture:** 계산·저장은 기존 `scripts/cluster.py`(`run`, `apply`)를 그대로 쓰고, 저장 시 화면용 스냅숏을 `workspace/typify/<cat>.applied.json`에 남기도록 `apply`를 넓힌다. UI 서버에 `scripts/ui/api_typify.py`(상태 조회, 실행 작업, 저장)를 더한다. 실행은 콘티 만들기와 같은 작업(Job) 방식: 끝나면 `awaiting` 미리보기 항목을 두고 작업은 `done`. 프런트는 `pages/typify.js`.

**Tech Stack:** Python 3.11 stdlib + 기존 numpy/PyYAML, `scripts/claude_cli.py`, 바닐라 JS ES 모듈, pytest.

**Spec:** 채팅에서 승인된 설명(2026-10-24), 아래 "승인된 범위". 해석 규칙: `skills/yt-typify/SKILL.md`. 터미널 흐름: `commands/yt-typify.md`.

### 승인된 범위
- 진입: 카테고리의 ref 수, 단계(예비 5~9 / 정식 10+), 마지막 유형화 날짜. 저장된 결과가 있으면 바로 표시. ref 5개 미만이면 "N개 더 필요" + "레퍼런스 추가로 가기". "내 영상은 기준에 섞지 않습니다" 한 줄.
- "유형화 실행": 계산 → Claude 해석(1회) 진행 상태 표시 → 저장 전 미리보기.
  - 축별 판정 표: 축 이름, 판정 배지(유형 있음 / 약한 경향 / 유형 없음 / 데이터 부족), 영상 수 n · 묶음 수 k, 근거 문장(고칠 수 있음).
  - 아키타입 카드: 영상 수, 골격 색 띠(`.lb-*`), 평균 길이, 평균 컷, 대표 영상, 구성 영상(누르면 `#/refs/<id>`), 이름 입력(Claude 제안, `prev_name`을 이어받았으면 "이전 이름 그대로" 표시).
  - 이상치: 영상(링크) + 떨어진 축.
  - "저장"을 눌러야 `index.md`에 기록. 안내: "영상 라벨이 잘못됐다면 레퍼런스 목록에서 고친 뒤 다시 실행".
- 근거 문장도 고칠 수 있다(내 결정). 저장 시 스냅숏을 `workspace/`에 남긴다(터미널 저장도 같은 파일). 저장하면 홈 진행 단계 갱신.
- 빼는 것: 판정 기준값 조정, 영상 수동 재배치.

## Global Constraints
- mine은 유형화에 절대 섞지 않는다(`features.load_videos`가 ref만 — 건드리지 않음).
- AI 출력은 제안: 저장은 사용자가 "저장"을 눌렀을 때만. Claude 호출은 사용자가 "유형화 실행"을 눌렀을 때만(화면 진입 시 자동 호출 금지).
- `index.md`의 `## 내 메모`와 다른 본문은 기존 `apply`처럼 `## 판정`/`## 아키타입`/`## 이상치` 섹션만 바꾼다.
- 축 키·판정 값은 `cluster`/`features` 그대로(`structure, hook, narrative, title, pacing, shots`; `typable, weak, untypable, insufficient`). 한국어 표시는 `cluster.VERDICT_KO`와 같은 문구.
- 새 의존성 금지. 프런트 규칙(innerHTML 금지, `h()`/`fill()`만, 정적 파일에 `http(s)://` 금지, 페이지 계약, `isCurrent()`/`alive` 가드, `ctx.api` 사용)은 기존과 같다.
- 사용자 대면 한국어, 식별자 영문. 커밋 Conventional Commit, Claude 서명 없음.

## Review Focus
1. 미리보기를 띄운 사이 다른 실행(다른 탭·터미널 `cluster run`)이 결과 json을 바꿈 → 저장이 `typify_changed`로 거부(run_at 비교), index.md 그대로. (Task 1 테스트)
2. Claude 응답에 축 문장·아키타입 이름이 빠짐 → 1회 재시도(`ask_validated`), 그래도 빠지면 작업 실패 메시지, 아무것도 저장 안 됨. (Task 1 테스트)
3. 사용자가 이름을 비우고 저장 → `invalid_notes` 메시지가 화면에 보이고 입력값 유지. (Task 1 테스트 + Task 2)
4. ref 4개 카테고리에서 실행 → `too_few`로 안내, Claude 호출 없음. (Task 1 테스트)
5. 실행 중 다른 화면으로 갔다 돌아옴 → `GET /api/jobs/current?kind=typify`로 진행/미리보기를 되살림. (Task 2)
