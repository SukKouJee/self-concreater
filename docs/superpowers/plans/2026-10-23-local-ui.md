# 로컬 UI 1차 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** yt-coach를 내 PC에서만 열리는 웹 화면(왼쪽 메뉴 · 홈 · 레퍼런스 추가 · 콘티 컷 대안 편집)으로 쓸 수 있게 한다.

**Architecture:** 표준 라이브러리 `ThreadingHTTPServer` 하나가 정적 화면(빌드 없는 HTML/CSS/ES 모듈)과 JSON API를 낸다. API는 기존 `scripts.*` 함수를 직접 부르고, 해석이 필요한 일은 `claude -p`를 하위 프로세스로 부른다(`scripts/claude_cli.py`). 오래 걸리는 일은 서버 메모리의 작업(job)으로 돌리고 화면은 폴링한다. 원본은 여전히 작업 폴더 md다.

**Tech Stack:** Python 3.11+ 표준 라이브러리(http.server, threading, subprocess, hashlib), 기존 의존성만. 프런트엔드는 빌드 없는 vanilla JS(ES modules). pytest.

**Spec:** `docs/superpowers/specs/2026-10-23-local-ui-design.md`

## Global Constraints

- 새 Python 의존성 없음. `requirements.txt` 변경 없음.
- 서버는 `127.0.0.1`에만 바인딩. 토큰 없는 요청과 `Host`가 `127.0.0.1:<port>`/`localhost:<port>`가 아닌 요청은 403.
- md 프런트매터가 유일한 원본. 본문과 `## 내 메모`는 덮어쓰지 않는다(콘티 md 본문은 기존 `save`처럼 프런트매터로 다시 그리되 메모 보존).
- AI 출력은 사용자의 저장/이걸로 바꾸기 클릭 없이 파일에 쓰지 않는다(예외: `--shots-only` 경로, `script_mismatch` 자동 맞춤 — 기존과 같음).
- 수집 작업(fetch/cuts/stt)은 서버 안에서 동시에 하나. 영상은 하나씩.
- 기존 `scripts.*`의 CLI JSON 계약은 바꾸지 않는다(추가만).
- 사용자 대면 문구는 한국어, 식별자는 영어. 커밋은 Conventional Commit, Claude 서명 없음.
- Windows가 주 환경: 한글·공백 경로, CRLF md를 견딘다.
- 콘티 `SCHEMA_VERSION` 1 → 2 (`cuts[].ref_frame` 선택 필드). 없는 파일은 자동 매칭 그대로.
- 대사 대안: 처음 3개, 더 보기 3개씩. 레퍼런스 장면 최대 6장. 컷 최대 글자 수 = `int(speech_cps * sec)`.

## Review Focus

1. 한글·공백이 든 draft/콘티 파일명이 URL(`/files/…`, `?path=`)을 오가도 같은 파일을 가리켜야 한다 → Task 4 `test_files_serves_korean_name`, Task 6 `test_get_conti_korean_path`.
2. 서버를 다시 켜면 열려 있던 탭의 옛 토큰이 403을 받는다 → 화면은 빈 화면 대신 "서버가 다시 켜졌습니다. 터미널의 새 주소로 여세요"를 보여야 한다 → Task 7 수동 확인 + Task 4 `test_api_403_body_has_code`(`{"error":"bad_token"}`).
3. `claude`가 없거나 로그인 안 됨/시간 초과/JSON 아닌 출력 → 그 영상만 실패 표시하고 작업은 다음 영상으로 간다(분석 단계), 콘티 화면은 이유 한 줄 → Task 3 `test_ask_*`, Task 5 `test_add_claude_failure_marks_video_and_continues`.
4. 고정한 `ref_frame` 파일이 지워졌거나(프레임 정리) 사용자가 md에서 지운 경우 → 자동 매칭으로 돌아가야 한다 → Task 2 `test_render_missing_ref_frame_falls_back`.
5. 확인 대기 중 브라우저를 닫았다 다시 열면 그 카드가 그대로 보여야 한다 → Task 5 `test_current_job_snapshot_keeps_awaiting_preview`.

- `validate`는 컷의 `ref_frame`(문자열, 비어 있지 않을 때만)을 그대로 통과시킨다.

- `line`을 바꾸면 그 컷 섹션의 `script[i].text` = 그 섹션 컷 `line`들 중 빈 것 제외하고 `" "`로 이은 것.
- 저장: 프런트매터의 `cuts`/`script` 갱신, `schema_version = 2`, 본문은 `render_md(fm, memo)`로 다시(메모 보존), HTML 다시 그림. 원래 줄바꿈(CRLF/LF)은 유지.

- `cut_context`의 `hook_type/narrative_type`은 콘티 fm의 `draft` 파일 프런트매터에서(없으면 None), `max_chars = int(speech_cps * cut.sec)`.

**Interfaces:**
- Produces:
  - `claude_cli.find_claude() -> str` — `shutil.which("claude")`, 없으면 `ScriptError("claude_missing", "Claude Code CLI(claude)를 찾을 수 없습니다. 설치 후 터미널에서 claude를 한 번 실행해 로그인하세요")`.
  - `claude_cli.ask(rules: list[Path], payload: dict, task: str, *, schema: dict | None = None, tools: list[str] | None = None, timeout: int = 600) -> dict`
  - `claude_cli.ask_validated(rules, payload, task, validate: Callable[[dict], Any], **kw) -> tuple[dict, Any]` — `validate`가 `code.startswith("invalid_")`인 ScriptError를 내면 그 message를 task 끝에 `"\n\n이전 출력이 거절됐습니다: {message}\n고쳐서 다시 출력하세요."`로 붙여 **한 번** 다시 묻는다. 두 번째도 실패하면 그 ScriptError를 그대로 올린다. 성공하면 `(data, validate(data))`.
  - `claude_cli.SKILLS_DIR = PLUGIN_ROOT / "skills"`.

호출 방식(정해진 것): 프롬프트 = 규칙 파일 내용들 + `"## 입력\n```json\n{payload}\n```\n\n## 할 일\n{task}\n\n출력은 JSON 하나만."`, **stdin으로** 전달(Windows 인자 길이 제한 회피). 명령: `[claude, "-p", "--output-format", "json", "--no-session-persistence"]` + (schema가 있으면 `["--json-schema", json.dumps(schema)]`) + (tools가 있으면 `["--allowedTools", ",".join(tools)]`, 없으면 도구 없이 — 정확한 플래그는 Step 0 확인 결과로). `cwd=work_root()`, `encoding="utf-8"`, `timeout`.
결과 해석: stdout JSON의 `is_error`가 참 → `ScriptError("claude_failed", <result 앞 200자>)`; 로그인 관련 문구(`"login"`, `"/login"`, `"authenticate"`) 포함 시 message를 `"Claude에 로그인되어 있지 않습니다. 터미널에서 claude를 실행해 로그인하세요"`로. `structured_output`이 dict면 그것, 아니면 `result` 문자열에서 첫 `{`부터 마지막 `}`까지(코드 펜스 제거) JSON 파싱, 실패 → `claude_failed`. `TimeoutExpired` → `claude_failed`("시간 초과"). 0이 아닌 종료 코드이고 stdout이 JSON이 아니면 → `claude_failed`(stderr 앞 200자).
