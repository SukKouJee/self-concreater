# 장면 그림(일러스트 콘티) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 콘티 장면마다 Claude가 그린 SVG 일러스트를 붙이고, 장면의 action·guide·size를 고치면 그 장면을 자동으로 다시 그린다.

**Architecture:** 새 모듈 `scripts/conti_art.py`가 basis(해시)·상태·SVG 검사·그리기·저장을 맡고, 컷 프런트매터의 선택 필드 `art: {file, basis}`에 결과를 둔다. 기존 사진 경로(`cut_refs`)는 바꾸지 않고, 보이는 쪽(view·HTML·화면)에서 "고정 사진 > 그림 > 사진 > 도식" 순서로 고른다. 작업은 job kind `conti_art`(사진 고르기 패턴), 자동 다시 그리기는 콘티 화면의 디바운스.

**Tech Stack:** Python 3.11 표준 라이브러리(xml.etree, hashlib), 기존 `scripts/llm.py` 엔진, vanilla ES modules(`h()` from `/static/dom.js`), pytest(+ node로 도는 js 유틸 테스트 패턴).

**Spec:** `docs/superpowers/specs/2026-10-30-scene-art-design.md` (특히 "빌더 점검 뒤 정한 것" 1~7이 본문보다 우선)

## Global Constraints
- 사용자 대면 문구·스킬 프롬프트는 한국어. 커밋 제목 Conventional Commit, Claude 서명·Co-Authored-By 금지.
- md 본문과 `## 내 메모`는 절대 덮어쓰지 않는다. 콘티 쓰기는 모두 `conti._write_conti_file`을 거친다.

- 새 의존성 없음. innerHTML·confirm·외부 URL 금지(정적 UI). SVG는 `<img>`로만 보여 준다.
- 프로세스를 이미지 이름으로 끄지 않는다. 테스트 서버는 작업 폴더 사본으로, 사본의 `workspace/ui.lock`을 지운 뒤 띄운다.
- 테스트: `C:/ai/projects/orca/nahon-creater/.venv/Scripts/python.exe -X utf8 -m pytest tests/<file> -q -p no:cacheprovider`

## Review Focus
- 그리는 사이 사용자가 그 장면을 고침 → 그 장면 결과는 버려지고 새 basis로 stale 유지(Task 3 테스트).
- Claude가 `<script>`·`onload`·외부 `href`·`<image>`를 넣은 SVG → 제거되거나 거절되고 파일엔 안전한 SVG만(Task 2 테스트).
- 고정 사진이 있는 장면 → 그림이 있어도 화면·HTML 모두 고정 사진(Task 4 테스트).
- 연달아 세 번 고침 → 작업은 한 번만 시작(Task 6 js 유틸 테스트).
- 이력에서 옛 버전 복원 → 그 버전의 `art` 파일이 남아 있어 그림이 그대로 보임(Task 4 테스트).
