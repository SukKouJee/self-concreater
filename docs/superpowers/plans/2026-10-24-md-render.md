# 마크다운 렌더링 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 로컬 UI 상세 화면의 md 본문(레퍼런스 상세, 기획안 상세)을 글자 그대로가 아니라 마크다운으로 렌더링한다.

**Architecture:** 외부 라이브러리 없이 작은 렌더러 `scripts/ui/static/md.js`(ES 모듈, `h()`로 DOM 생성 — `innerHTML` 금지)를 만들고, `pages/refs.js`·`pages/draft.js`의 본문 블록이 이것을 쓴다.

**Spec:** 채팅에서 승인(2026-10-24) — 아래 "승인된 범위".

### 승인된 범위
- 외부 라이브러리 없이 작은 렌더러를 직접 만든다(외부 리소스 금지, `innerHTML` 금지). 화면 요소를 하나씩 만들어 그리므로 메모에 HTML을 적어도 실행되지 않고 글자로만 보인다.
- 지원: 제목(`#`~`######`), 목록(`-`/`*`, `1.`; 한 단계 들여쓰기 중첩), 인용(`>`), 표(헤더 + `|---|` 구분 줄), 굵게(`**`), 기울임(`*`/`_`), 인라인 코드(`` ` ``), 코드 블록(```` ``` ````), 구분선(`---`/`***`), 줄바꿈·문단.
- 링크: `[글](videos/<id>.md)`·`(../videos/<id>.md)` 등 `videos/<id>.md`로 끝나는 링크 → `#/refs/<id>`; `https://(www.|m.)youtube.com/…`·`https://youtu.be/…` → 새 탭(`target=_blank rel="noopener noreferrer"`); 그 밖은 링크로 만들지 않고 글자(링크 글 + 괄호 주소)로.
- 기획안 저장 보호 표시 `\#`, `\|`(그리고 표 칸 안의 `\|`)는 원래 글자로 보인다. 일반 마크다운 이스케이프 `\*`, `\_`, `` \` ``, `\[`, `\]`, `\\`도 글자로.
- 적용: 레퍼런스 상세·기획안 상세의 본문 블록(대본·샷 표·아키타입 비교·패키징·내 메모 등). 블록 제목(h2)은 지금처럼 화면이 그리고, 블록 안 내용만 렌더러로.

## Global Constraints
- `innerHTML`/`insertAdjacentHTML`/`outerHTML`/`document.write`/`eval`/`new Function` 금지. 텍스트는 `textContent`/텍스트 노드로만. 정적 파일에 `http://`·`https://` 문자열 금지(기존 테스트) — 유튜브 주소 판별 정규식은 `"https:" + "//"` 식으로 문자열을 나눠 쓰지 말고, 프로토콜을 `/^https:$/`처럼 URL 객체(`new URL`)의 `protocol`/`hostname`으로 판별한다.
- 표는 가로가 넘치면 블록 안에서만 가로 스크롤(`.table-wrap`), 페이지 가로 스크롤 없음. 다크 모드는 기존 토큰만.
- 렌더러는 순수 함수 `renderMarkdown(text: string): DocumentFragment`(+ 내부 파서). 입력이 아주 길거나(10만 자) 이상해도(닫히지 않은 `**`, 칸 수가 다른 표, 빈 줄만) 예외 없이 그린다.
- 사용자 대면 한국어, 식별자 영문. 커밋 Conventional Commit, Claude 서명 없음.

## Review Focus
1. 메모에 `<script>`, `<img onerror>`, `[x](javascript:alert(1))`, `[x](data:…)` → 글자로만 보이고 링크·실행 없음.
2. 기획안 샷 표(`| # | 샷 | 앵글 | 길이 | 내용 |`, 내용에 `\|`) → 표로, `\|`는 칸 안 글자 `|`.
3. `### 0:00–0:04 · hook (4초)` 같은 소제목 + 대본 줄(`자막: …`)이 줄마다 보존(문단 안 줄바꿈 유지 — 대본은 줄 단위 의미가 있으므로 한 줄 줄바꿈을 `<br>`로).
4. 패키징 이력의 인용(`    > 자막: …` 들여쓴 목록 안 인용) → 깨지지 않고 읽힘(완벽한 중첩이 아니어도 텍스트 손실 없음).
5. 레퍼런스 md의 근거 링크 `[a00](videos/a00.md) 제목` → `#/refs/a00`.
