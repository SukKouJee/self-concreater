# 레퍼런스 목록 편집 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 레퍼런스 상세 화면에서 섹션 라벨 · body 세부 유형 · 훅 유형 · 서사 유형을 고쳐 md 프런트매터에 저장한다.

**Architecture:** 계산·저장 규칙은 `scripts/videomd.py`의 새 함수 `relabel()`(+ CLI `relabel`)에 두고, UI 서버는 `POST /api/refs/<id>/labels`로 그 함수를 부른다. 상세 API는 충돌 확인용 `hash`와 선택지 `vocab`을 더 내려 준다. 프런트는 상세 화면에 "고치기" 모드를 더한다.

**Tech Stack:** Python 3.11 stdlib + 기존 PyYAML, 바닐라 JS ES 모듈, pytest.

**Spec:** 채팅에서 승인된 설명(2026-10-24), 아래 "승인된 범위". 선행 기능: `docs/superpowers/plans/2026-10-24-ref-list.md`(보기 전용 목록, 머지됨).

### 승인된 범위
- 상세 화면에서 섹션 라벨, body 세부 유형(sub), 훅 유형, 서사 유형을 드롭다운으로 고친다(레퍼런스 추가 확인 단계와 같은 방식).
- 저장은 md **프런트매터만** 고친다. 본문과 `## 내 메모`는 바이트 그대로 둔다. 본문 `## 섹션` 표도 고치지 않는다(사용자 결정: 추천안).
  - 대신 상세 화면에서 본문 `## 섹션` 블록 제목 옆에 "분석 당시 기록" 표시를 달고, 기준 라벨은 위쪽 섹션 목록이라는 안내를 둔다.
- 저장하면 `reviewed: true`가 된다(다음 분석의 교정 예시로 쓰임).
- 화면을 연 뒤 md가 밖에서 바뀌었으면 덮어쓰지 않고 다시 불러오라고 알린다(파일 sha256 비교).
- 빼는 것: 섹션 구간 시간 조정, 섹션 추가·삭제, 삭제, 재분석.

## Global Constraints
- 라벨·유형 값은 `videomd.LABELS`, `BODY_SUBS`, `HOOK_TYPES`, `NARRATIVE_TYPES`만 허용(설계서 5절 고정). `sub`는 `label == "body"`일 때만 있을 수 있고, body가 아니게 바뀌면 지운다.
- 섹션 개수·순서·`start`/`end`는 바꾸지 않는다(요청에 들어 있어도 기존 값 유지가 아니라 **불일치면 거부**: `invalid_labels`).
- 본문 바이트(첫 `---` 블록 뒤 전부)는 저장 전후 같아야 한다. 줄바꿈 방식(CRLF/LF)도 유지(`refstore.update_frontmatter`가 이미 그렇게 한다).
- 새 의존성 금지. 프런트 규칙(innerHTML 금지, `h()`만, 정적 파일에 `http(s)://` 금지, 페이지 계약, `isCurrent()`)은 기존과 같다.
- 사용자 대면 문구 한국어, 식별자 영문. 커밋 Conventional Commit, Claude 서명 없음.
- 저장 버튼은 사용자가 누를 때만(자동 저장 없음).

## Review Focus
1. 화면을 연 사이 터미널에서 md를 고침 → 저장이 `ref_changed`로 거부되고 파일은 그대로. (Task 1 테스트)
2. CRLF md · BOM md · `## 내 메모`가 있는 md → 저장 후 본문 바이트 동일, 줄바꿈 유지. (Task 1 테스트)
3. 라벨을 body → hook으로 바꾸면 sub가 사라지고, hook → body로 바꾸면 sub를 골라야 저장된다(sub 없는 body는 허용 — 분석에서도 선택 사항이면 허용, 아래 Task 1 Step 3 참고). (Task 1 테스트)
4. 저장 중 빠르게 다른 영상으로 이동·카테고리 변경 → 이전 응답이 새 화면을 덮지 않음. (Task 2 정적 확인)
5. 저장 실패(충돌·검증 오류) 시 고친 선택값이 사라지지 않고 메시지가 보임. (Task 2)

- Produces:
  - `videomd.relabel(video_id: str, category: str, changes: dict, expected_hash: str) -> dict`
    - `changes = {"sections": [{"label": str, "sub"?: str}, ...] (선택), "hook_type"?: str, "narrative_type"?: str}` — 들어온 키만 바꾼다. `sections`는 기존과 같은 길이, i번째가 기존 i번째에 대응.
    - 반환 `{"id", "md": 상대경로, "hash": 저장 후 sha256, "changed": [바뀐 필드 이름 목록], "reviewed": True}`
    - 아무것도 안 바뀌면 파일을 쓰지 않고 `changed: []`, `hash`는 기존 값(이 경우 `reviewed`도 바꾸지 않고 현재 값을 그대로 반환).
  - CLI: `python -m scripts.videomd relabel <id> --category <c> --changes <json 파일> --hash <sha256>`
  - `GET /api/refs/<id>?category=` 응답에 `"hash": str`, `"vocab": {"label": LABELS, "body_sub": BODY_SUBS, "hook_type": HOOK_TYPES, "narrative_type": NARRATIVE_TYPES}` 추가.
  - `POST /api/refs/<id>/labels?category=<c>` 본문 `{"hash": str, "sections"?: [...], "hook_type"?: str, "narrative_type"?: str}` → `relabel` 결과 + `"video"`(목록과 같은 Summary 형태로 다시 만든 것).

동작:
- 상세의 섹션 구간 블록 제목 옆에 버튼 "라벨 고치기". 누르면 그 블록이 편집 폼으로 바뀐다:
  - 섹션마다 한 줄: `m:ss–m:ss` + 라벨 `select`(vocab.label, `aria-label="m:ss 섹션 라벨"`) + 라벨이 body일 때만 보이는 세부 유형 `select`(첫 옵션 "(없음)" = 값 없음, vocab.body_sub).
  - 훅 유형 `select`, 서사 유형 `select`(vocab, 현재 값 선택; 현재 값이 vocab에 없으면 그 값을 맨 앞 옵션으로 넣어 보존).
  - 섹션 띠는 고르는 대로 즉시 미리 바뀐다(`.lb-*`).
  - 버튼 "저장", "취소". 바뀐 게 없으면 저장 비활성.
- 저장: 바뀐 필드만 보낸다(sections는 바뀐 게 하나라도 있으면 전체 배열 `{label, sub?}`). 진행 중엔 버튼 비활성 + "저장 중…".
  - 성공: `ctx.toast("저장했습니다 — 다음 분석 때 교정 예시로 쓰입니다")`, 상세를 다시 불러와 보기 모드로.
  - `ref_changed`: 폼은 그대로 두고 경고 문구 + 버튼 "다시 불러오기"(누르면 상세 재로딩, 고친 값은 버림 — 버튼 옆에 그렇게 적는다).
  - 기타 오류: 폼 유지, `p.error[role=alert]`에 message.
- 보기 모드의 본문 블록 중 heading이 `섹션`인 블록 제목 옆에 작은 배지 "분석 당시 기록"과 `title`/설명 "라벨을 고치면 위 섹션 목록이 기준이 됩니다. 이 표는 바뀌지 않습니다".
