현재 폴더를 yt-coach 작업 폴더로 초기화한다. 모든 대화는 한국어로 하고, 파일을 쓰기 전에는 반드시 사용자 확인을 받는다.

스크립트 실행기: `"${CLAUDE_PLUGIN_ROOT}/bin/ytc"` (아래에서 `ytc`로 줄여 씀. 실제 호출은 항상 전체 경로로)
템플릿 폴더: `${CLAUDE_PLUGIN_ROOT}/templates/`
인자: `$ARGUMENTS` (있으면 첫 카테고리 이름 후보)

## 1. 폴더 구조

`ytc refstore scaffold`를 실행한다. 출력 JSON의 `profile_exists`, `git`, `categories`를 기억한다.
- 실패 JSON(`error`)이면 `message`를 그대로 보여주고 멈춘다.
- `profile_exists`가 true면 "이미 초기화된 폴더"라고 알리고 2~4단계를 건너뛴 뒤, 새 카테고리를 추가할지만 묻는다(5단계).

## 2. git 제안

`git`이 false면 이렇게 묻는다: "교정 이력(md를 고친 기록)을 남기려면 이 폴더를 git으로 관리하는 걸 권합니다. `git init`을 할까요?"
- 동의하면 `git init` 후 첫 커밋은 하지 않는다(사용자가 원할 때 한다).

## 3. 인터뷰

질문은 한 번에 하나씩, 짧게 한다. 사용자가 "모름/나중에"라고 하면 빈칸으로 두고 넘어간다.
1. 관심 주제: 어떤 주제의 영상을 만들고 싶나요? (여러 개 가능)
2. 포맷: 쇼츠, 롱폼, 둘 다 중 무엇인가요?
3. 롤모델: 참고하고 싶은 채널이 있나요? (이름이나 링크. 링크를 받아도 수집하지 않고 기록만 한다)
4. 하루 시간: 하루에 몇 분 정도 쓸 수 있나요?
5. 피하고 싶은 스타일: 하기 싫거나 어울리지 않는 방식이 있나요? (예: 얼굴 출연, 과한 자막, 빠른 컷)

## 4. profile.md

`${CLAUDE_PLUGIN_ROOT}/templates/profile.md`를 읽고 그 구조 그대로 초안을 만든다.
- 프런트매터 `created`, `updated`는 오늘 날짜(YYYY-MM-DD).
- 인터뷰 답을 해당 섹션에 짧은 bullet로 채운다. `## 강점`, `## 약점`은 비워 둔다(미션·회고에서 채움).
- `## 성장 단계`는 `관찰`.
- 초안 전체를 보여주고 "이대로 저장할까요? 고칠 곳이 있으면 말해 주세요"라고 묻는다. 확인을 받은 뒤에만 `profile.md`로 저장한다.

## 5. 첫 카테고리

카테고리는 비슷한 영상끼리 모으는 단위다(유형화도 카테고리 안에서만 한다).
- 관심 주제(또는 `$ARGUMENTS`)에서 하나를 골라 이름을 제안한다. 이름은 영문 소문자·숫자·`-`·`_`만 쓴다.
  예: "요리 쇼츠" → `cooking`, "자취 꿀팁" → `living-tips`
- 확인을 받으면 `ytc refstore init <category>`를 실행한다.
- 사용자가 이 카테고리에서 어떤 영상을 모을지 한두 문장 말해 주면, `refs/ref_<category>/index.md`의 `## 개요` 섹션에 넣는다(그 섹션만 고친다).

## 6. 마무리 안내

아래 형식으로 끝낸다.

```
✅ 준비 완료
- 프로필: profile.md
- 카테고리: refs/ref_<category>/ (현재 단계 1 · ref 0개)

다음: 마음에 드는 영상 링크 3개부터 넣어 보세요.
  /yt-coach:yt-add <category> <링크1> <링크2> <링크3>
5개가 모이면 비슷한 구조가 보이기 시작하고, 10개부터 정식 유형화를 할 수 있습니다.
```
